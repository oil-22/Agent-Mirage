## 每行格式和标签

正式 JSONL 每行恰有三个字段：`images`（两个相对路径，依次加载）、`prompt`（含该次分发动作 JSON 的完整英文 Jev 原生提示）、`label`（大写 `YES` 或 `NO`）。解压后保留 JSONL 和 `images/` 的相对位置。[protocol.json](protocol.json) 单独保存全局 system 指令；原生 Jev 选项 A 对应 YES，B 对应 NO。使用项目原生 builder 时只传前图、动作、候选图，不要再把完整的导出 prompt 拼入 state。

**YES** 表示相关界面已显示可辨认的结果。明确的操作失败提示也是结果；已经看到完整页脚时继续向下滚动，也可有证据地判 YES。**NO** 表示第二张图不能说明这次动作的结果：例如还是旧列表、输入框显示了另一段文字，或只剩无关按钮。没有第二张图的静默丢帧不构成双图样本。

## 训练样本从哪里来

| 来源 | YES | NO | 如何定标 |
| --- | ---: | ---: | --- |
| 上一版保留的实收图像对 | 1,120 | 79 | 保留原监督和来源。 |
| 补充审核的正常实收图像对 | 535 | 0 | 497 条来自自然 Classifieds 实验，38 条来自早期 VisualWebArena。核对导航后的已渲染内容、滚动位置与可见内容、实际输入文字、焦点框或明确可见的滚动边界。 |
| 旧实验实际交付过的异常候选 | 0 | 272 | 151 条全白、102 条旧帧、19 条局部画面。使用实际送入请求的图片；局部画面只在剩余控件未变且遮掉了正常结果时入选。 |
| 离线构造的反例 | 0 | 1,834 | 1,470 条回放同一动作的前图；260 条取同轨迹更早的同页画面，跳转结果尚不可见；16 条取同轨迹旧画面，目标输入控件仍保持原状；88 条使用同一起始输入框中另一个经识别的实际值。 |

训练集有 **2,006 条实收、1,834 条构造**；验证及测试全部实收。因此全库共有 **2,625 条实收、1,834 条构造**。这里数的是不同的“双图＋动作提示”输入。正反例可以共享同一次历史动作和第一张图，不能把这些样本解释成同样多次独立运行。

每条构造反例都指向训练集内一个实际出现且结果可见的 YES，保留其真实结果图、候选图的来源，以及为什么这个候选不足以说明结果。构造的是**配对关系**；没有捏造新的截图、动作或交付回执。模型输入不含来源、采集时间或定标理由。

## 校验和复用

- [manifest.jsonl](manifest.jsonl) 与 [audit.jsonl](audit.jsonl) 用 sample_id 对齐。前者给出划分、动作、图像摘要、标签与来源类型；后者记录实际日志索引、正例对照、捐献截图或局部像素证据。构造记录标记 `pair_observed=false`，配对回执和候选 capture_id 为 null。原正例的回执只证明原正例。
- [validation.json](validation.json) 记录逐行核验结果。训练输入按图像字节、解码像素、手机状态栏差异和相同画面上 6 像素内的等价点击去重。原有验证／测试文件逐字节保持不变。训练和留出集不共享截图、来源轨迹或事件；检查了 15 张回归参考图及其解码像素。模型输入使用 2,689 张原图，另有 21 张仅用于审核的原图。
- 全量提示与历史原生 Encoder.messages 格式核对；另对新增的 13 种证据各抽 3 条做了看图复核，见 [spot-check.json](spot-check.json)。这是一套按证据规则标注并抽查的数据，没有逐条人工盲标。完整规则与重建入口在 [build/](build/)；重建需原项目与其历史归档，读取成品和运行下列便携校验不需访问实验服务器。
- 在解压目录用 `python verify.py` 可重查双图、标签、原生文本模板、来源对照、去重、留出隔离和平衡子集；需 Python 3.11+ 和 Pillow。项目原有 temporal_head 只接受有实收回执的监督行；在原仓库内用 `python native_head_v2.py check manifest.jsonl` 可按 v2 的两种来源规则校验，后续使用原流程的 fit/test 子命令。构建此版本没有启动训练。

解读训练结果时，可以把“图片相同”和“图片不同”分开看：完整训练集有 **44 条前后画面相同的 YES**，也有 **543 条画面不同的 NO**。只凭图片是否相同会误判这两组。新样本集中在 Classifieds；保留的 Android 验证集和 Reddit／受控测试集中 NO 分别只有 17 和 14 条，报告误放率时请同时给出例数。
